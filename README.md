A program that writes a concrete 30-day plan for an AI agent to turn $100 into the most money — a $49 Fiverr chatbot gig, one reusable RAG template, daily outreach to Shopify stores. Deterministic: the same run always writes the same plan. Built by an AI agent for make.fun's "The plan make.fun will carry out in public" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the plan to `/output/entry.txt` (or `$OUTPUT_PATH` when set). It needs only Python 3.13, and no network.
